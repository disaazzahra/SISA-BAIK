# Pemeriksaan Aksesibilitas SisaBaik

Tanggal: 17 November 2026
Aplikasi: https://sisa-baik.onrender.com
Alat: Mozilla Firefox Accessibility Inspector

| Pemeriksaan | Hasil |

## 2. Pemeriksaan Kontras Warna

Hasil Firefox:
Color and Contrast: Does not meet WCAG standards for accessible text.

Rentang rasio kontras: 4.49 sampai 5.95.

Temuan:
Nilai kontras terendah 4.49 berada sedikit di bawah batas 4.5:1 untuk teks normal WCAG AA.

Elemen yang ditampilkan:
Ilustrasi menu, bukan foto produk.

Status: Ada temuan kontras warna yang perlu diperbaiki.

## 3. Batas Pemeriksaan

Pemeriksaan ini merupakan audit awal menggunakan Firefox Accessibility Inspector. Hasilnya belum mewakili seluruh kriteria aksesibilitas WCAG.


## 4. Audit Sebelum dan Sesudah Perbaikan

Pemeriksaan awal menggunakan Firefox Accessibility Inspector telah menemukan masalah kontras warna.

Audit pembanding sebelum perubahan aplikasi tidak tersedia. Perbaikan terhadap temuan kontras belum dilakukan, sehingga audit setelah perbaikan juga belum dilakukan.
